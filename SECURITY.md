# Security policy

## Reporting a vulnerability

Do not open a public issue. Use GitHub's private reporting instead:
<https://github.com/chokr-ai/chokr-policy-language/security/advisories/new>

Include the policy or expression, the action, the verdict you got and the verdict you expected. A case where a
policy allows something it should deny is a security bug, so please report it even if it looks like a language quirk.

## Supported versions

The project is in alpha. Only the latest release receives fixes.
